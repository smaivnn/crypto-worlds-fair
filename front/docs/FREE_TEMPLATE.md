# 무료 결과 리포트 구조

## 1. 요약 카드

-   주욕망 이름
-   상징 아이콘
-   유저 노출 문장
-   주/보조 통합 문장
-   키워드 태그

예시 :

```
{{primary.code}} ({{primary.ko}})

“{{primary.userQuote}}”

{{primary.summaryEngine}}
{{secondary.summaryStyle}}

{{tags}}
```

## 2. 당신의 욕망 구조

-   주/보조 욕망 공용 설명
-   사주/점성 기반 개인화 문장 (1~2 문장)

```
{{primary.structureBase_1}}
{{primary.structureBase_2}}
{{secondary.structureStyle}}

{{personalizeLine}}  // (선택) 사주/점성 기반 1문장
```

## 3. 욕망이 켜지는 순간

-   욕망이 강해지는 관계/상황
-   상황 기반, 욕망이 도움이 되었을 법한 장면
-   공감 가능한 사건
-   욕망이 과해지기 쉬운 신호

```
{{trigger.line_1}}   // 어떤 상황에서 켜지는지
{{trigger.line_2}}   // 도움이 되었던 장면
{{trigger.line_3}}   // 과해지기 쉬운 신호
```

## 4. 관계에서 만드는 착각

-   반복 패턴
-   흔한 오해
-   오해가 관계에 미치는 영향

```
{{illusion.line_1}}  // 반복 패턴
{{illusion.line_2}}  // 흔한 오해
{{illusion.line_3}}  // 관계에 미치는 영향
```

## 5. 이성 관계·친밀 프리뷰

-   이성과의 관계에서 드러나는 긴장 구조
-   욕망이 드러나는 조건
-   위험해질 수 있는 지점
-   유료 해금 문장

```
{{primary.intimacyBase_1}}
{{secondary.intimacyStyle}}
{{primary.intimacyBase_2}}

{{paywallCTA}}       // 유료 해금 문장(고정)
```

# 부록 A. 주/보조 욕망 ‘표현 방식 문장 블록’ (Copy Blocks)

이 부록은 **무료 결과 문장을 AI 없이도 일관되게 조립**하기 위해, 문장을 “블록(세트)”으로 미리 정의해두는 규칙이다.

## A-1. 블록의 역할 정의

-   **주 욕망(Primary) 블록**: ‘무엇이 욕망을 켜는가’(엔진)를 말한다.
    -   주로 **요약 카드**와 각 섹션의 ‘기본 문장’에 사용
-   **보조 욕망(Secondary) 블록**: ‘그 욕망이 어떤 톤/방식으로 드러나는가’(표현 방식)를 말한다.
    -   주로 **요약 카드(통합 문장 2번째 문장)**, **구조 섹션 3번째 문장**, **친밀 프리뷰 2번째 문장**에 주입

## A-2. 선택 규칙(v1/v2/v3를 어떻게 고르나)

> 완전 랜덤 대신 **결정적 선택(Deterministic)** 을 사용한다.
> 같은 입력이면 항상 같은 문장이 선택되어 **새로고침/재방문에도 문장이 흔들리지 않는다.**

-   각 블록은 `v1/v2/v3` 3종 변주를 가진다.
-   선택 인덱스는 아래처럼 고른다.

```text
seed = hash(userKey + primaryType + secondaryType + sectionId)
idx  = seed % 3   // 0,1,2 중 하나
pick = variants[idx]

// userKey 예시: (birthDate + birthTime? + answers) 를 해시한 값
// sectionId 예시: summary, structure, trigger, illusion, intimacy
```

### 권장 주입 위치(무료)

-   **요약 카드 통합 문장**: Primary.summaryEngine + Secondary.summaryStyle
-   **당신의 욕망 구조**: Primary.structureBase(2문장) + Secondary.structureStyle(1문장) + (선택) 개인화 1문장
-   **욕망이 켜지는 순간**: trigger(3문장) // 주/보조를 직접 붙이지 말고 ‘상황 서술’로만 구성
-   **관계에서 만드는 착각**: illusion(3문장) // 주/보조를 직접 붙이지 말고 ‘패턴/오해’로만 구성
-   **친밀 프리뷰**: Primary.intimacyBase(1문장) + Secondary.intimacyStyle(1문장) + Primary.intimacyBase(추가 1문장) + CTA

## A-3. 조립(Assembly) 예시

### 예시) Primary=SOVEREIGN, Secondary=WITNESS

-   요약 카드 통합 문장
    -   Primary.summaryEngine.v2 + Secondary.summaryStyle.v2

```text
주도권이 내 손에 있을 때, 욕망은 가장 선명해집니다.
시선과 반응이 또렷해질수록 에너지가 빠르게 점화됩니다.
```

-   욕망 구조 섹션(권장 3~4문장)

    -   Primary.structureBase(고정 2문장)
    -   Secondary.structureStyle.v1
    -   (선택) personalizeLine 1문장

-   친밀 프리뷰 섹션(권장 3~4문장)
    -   Primary.intimacyBase(첫 문장)
    -   Secondary.intimacyStyle.v2
    -   Primary.intimacyBase(둘째 문장)
    -   CTA(고정)

# 부록 B. Primary(주 욕망) 요약 엔진 블록 (3종)

> `Primary.summaryEngine`는 **요약 카드 통합 문장 1번째 문장**으로 사용한다.

## SOVEREIGN

-   v1: 주도권을 쥐는 순간 욕망이 또렷해집니다.
-   v2: 내가 결정할 수 있을 때, 욕망은 가장 안정적으로 작동합니다.
-   v3: 선택권이 내 손에 있을 때, 욕망이 가장 선명해집니다.

## ANCHOR

-   v1: 예측 가능한 구조가 있을 때 욕망은 오래 유지됩니다.
-   v2: 흔들리지 않는 기준이 생기면, 욕망은 깊게 붙습니다.
-   v3: 안정이 확보될수록 욕망은 천천히 커집니다.

## GUARDIAN

-   v1: 누군가를 지키고 책임질 때 욕망이 켜집니다.
-   v2: 내가 필요한 역할을 하고 있을 때 에너지가 선명해집니다.
-   v3: 관계의 안전을 만들 때 욕망이 간접적으로 충족됩니다.

## WITNESS

-   v1: 타인의 반응 속에서 욕망이 빠르게 점화됩니다.
-   v2: 나를 향한 시선이 또렷해질수록 욕망이 살아납니다.
-   v3: 인정의 기류가 생기는 순간 욕망이 선명해집니다.

## MERGER

-   v1: 깊은 연결이 생길수록 욕망이 완전히 작동합니다.
-   v2: 정서적 융합의 밀도가 올라갈 때 욕망이 커집니다.
-   v3: ‘이어짐’이 느껴지는 순간 욕망이 가장 선명해집니다.

## DEVOTEE

-   v1: 의미가 붙는 순간 욕망은 오래 붙어서 움직입니다.
-   v2: 한 대상에 몰입할 때 욕망이 강하게 유지됩니다.
-   v3: ‘끝까지 가고 싶다’는 감각이 생기면 욕망이 점화됩니다.

## SEEKER
 
-   v1: 새로운 경험이 들어오면 욕망이 즉각 반응합니다.
-   v2: 변화가 시작될 때 욕망의 온도가 올라갑니다.
-   v3: 다음 장면이 열릴수록 욕망은 더 선명해집니다.

## REBELLION

-   v1: 금지가 스치는 순간 욕망이 강해집니다.
-   v2: 경계를 넘는 선택 앞에서 욕망이 점화됩니다.
-   v3: 통제의 틈이 보이면 욕망은 더 날카로워집니다.

## NOMAD

-   v1: 머무르지 않을 때 오히려 욕망이 자유로워집니다.
-   v2: 선택지가 열려 있을수록 욕망이 유지됩니다.
-   v3: 고정에서 벗어나는 순간 욕망이 다시 움직입니다.

## SPECTATOR

-   v1: 거리를 둘 때 욕망이 안전하게 유지됩니다.
-   v2: 한 발 떨어져 바라볼수록 욕망은 더 안정됩니다.
-   v3: 직접 뛰어들기 전의 여백에서 욕망이 유지됩니다.

## CURATOR

-   v1: 이해할 수 있을 때 욕망이 움직이기 시작합니다.
-   v2: 의미가 정리되는 순간 욕망이 켜집니다.
-   v3: 해석이 가능해질수록 욕망의 방향이 선명해집니다.

## ASCENDER

-   v1: 올라가고 있다는 감각이 욕망을 계속 켭니다.
-   v2: 성장의 궤도가 잡히면 욕망은 더 강해집니다.
-   v3: ‘더 위로’라는 방향이 보일 때 욕망이 선명해집니다.

# 부록 C. Secondary(보조 욕망) 표현 방식 블록 (섹션별 3종)

> `Secondary.*Style`은 **주 욕망 문장에 “덧붙여지는” 2번째 문장**으로 사용한다.

## SOVEREIGN

-   summaryStyle
    -   v1: 특히 선택권이 분명할수록 당신의 에너지는 더 안정적으로 모입니다.
    -   v2: 누가 결정하는지 흐려지는 순간, 욕망이 불편함으로 바뀌기 쉽습니다.
    -   v3: 관계에서도 ‘내가 나로 있을 수 있는 조건’이 먼저 잡혀야 합니다.
-   structureStyle
    -   v1: 여기에 ‘결정권’이 더해지면, 관계의 균형을 스스로 잡으려는 감각이 강해집니다.
    -   v2: 통제가 흔들릴수록 욕망은 긴장과 부담 사이를 오갑니다.
    -   v3: ‘내가 선택한다’는 감각이 사라지면 욕망의 온도가 급격히 떨어질 수 있습니다.
-   intimacyStyle
    -   v1: 이성 관계에서는 역할과 주도권이 분명해질수록 끌림이 선명해집니다.
    -   v2: 안전한 선 바로 앞의 긴장에서 욕망이 가장 민감해질 수 있습니다.
    -   v3: 주도권의 흐름이 뒤집히는 순간, 긴장과 끌림이 동시에 올라올 수 있습니다.

## ANCHOR

-   summaryStyle
    -   v1: 예측 가능한 리듬이 있을 때 욕망이 오래 유지됩니다.
    -   v2: 작은 불확실성이 쌓이면 욕망보다 경계가 먼저 올라올 수 있습니다.
    -   v3: 관계에서 신뢰의 축적이 곧 욕망의 연료가 됩니다.
-   structureStyle
    -   v1: 안정은 정체가 아니라, 무너지지 않는 ‘리듬’을 만드는 방식으로 나타납니다.
    -   v2: 변화가 잦을수록 욕망은 불안으로 전환되기 쉬운 편입니다.
    -   v3: 기준이 분명해질수록 관계에서도 욕망이 천천히 깊어질 수 있습니다.
-   intimacyStyle
    -   v1: 친밀은 갑자기 폭발하기보다, 안전이 확보된 뒤 천천히 올라오는 편입니다.
    -   v2: 예측 불가능한 긴장이 과해지면 욕망보다 경계가 먼저 올라올 수 있습니다.
    -   v3: ‘믿어도 된다’는 감각이 생길 때 욕망의 온도가 안정됩니다.

## GUARDIAN

-   summaryStyle
    -   v1: 상대가 기댈수록 당신은 더 또렷해지는 편입니다.
    -   v2: 돌봄이 깊어질수록 내 욕망은 뒤로 밀릴 수 있습니다.
    -   v3: 관계의 균형을 지키려는 욕망이 자연스럽게 작동합니다.
-   structureStyle
    -   v1: 보호는 따뜻함뿐 아니라, 관계의 안전을 관리하려는 감각으로도 나타납니다.
    -   v2: 책임이 늘수록 욕망은 강해지지만 동시에 소진 위험도 커질 수 있습니다.
    -   v3: ‘지키는 역할’이 굳어지면 내 욕망을 잊기 쉬운 편입니다.
-   intimacyStyle
    -   v1: 친밀은 돌봄을 통해 깊어지지만, 때로는 내가 주도해야 유지되는 긴장이 생길 수 있습니다.
    -   v2: 상대의 취약함이 보일수록 욕망이 더 강하게 반응할 수 있습니다.
    -   v3: 관계에서 ‘안전’을 만드는 순간, 끌림도 함께 커질 수 있습니다.

## WITNESS

-   summaryStyle
    -   v1: 타인의 반응이 분명할수록 욕망은 더 날카롭게 살아납니다.
    -   v2: 시선과 반응이 또렷해질수록 에너지가 빠르게 점화됩니다.
    -   v3: 반응의 온도가 올라갈수록 욕망도 함께 올라옵니다.
-   structureStyle
    -   v1: 여기에 ‘반응’이 더해지면, 이 욕망은 관계의 긴장으로 변하기 쉽습니다.
    -   v2: 특히 누가 나를 어떻게 보는지에 따라 욕망의 온도가 크게 달라집니다.
    -   v3: 관계에서 ‘확인’이 부족해지면 욕망이 불안으로 바뀔 수 있습니다.
-   intimacyStyle
    -   v1: 이성 관계에서는 상대의 반응이 선명할수록 끌림이 더 민감해집니다.
    -   v2: 친밀한 상황에서 ‘반응의 교환’이 있을 때 욕망이 빠르게 살아납니다.
    -   v3: 무관심처럼 느껴지는 순간, 욕망이 급격히 식을 수 있습니다.

## MERGER

-   summaryStyle
    -   v1: 거리보다 밀착이 커질수록 욕망이 자연스럽게 상승합니다.
    -   v2: 연결이 깊어지면 안정도 커지지만, 불안도 같이 커질 수 있습니다.
    -   v3: 관계의 온도와 밀도가 당신의 욕망을 직접 흔듭니다.
-   structureStyle
    -   v1: 연결은 따뜻함이지만, 동시에 경계가 낮아지는 선택이기도 합니다.
    -   v2: 밀도가 높아질수록 욕망은 커지지만, 이탈 불안도 같이 커질 수 있습니다.
    -   v3: ‘우리’의 감각이 강해질수록 욕망은 더 빨리 반응합니다.
-   intimacyStyle
    -   v1: 친밀은 거리보다 밀착에서 더 선명해지는 편입니다.
    -   v2: 상대와의 감정 교환이 깊어질수록 욕망의 온도가 올라갑니다.
    -   v3: 안전 장치가 없으면 욕망이 의존으로 바뀌기 쉬운 구간이 있습니다.

## DEVOTEE

-   summaryStyle
    -   v1: 관계에 ‘서사’가 생기면 쉽게 꺼지지 않습니다.
    -   v2: 한 번 의미가 붙으면 욕망은 오래 남아 움직입니다.
    -   v3: 끝까지 가려는 힘이 욕망의 형태로 나타납니다.
-   structureStyle
    -   v1: 헌신은 따뜻함이지만, 동시에 ‘끝까지’ 가려는 고집이 될 수 있습니다.
    -   v2: 목적이 흐려지면 욕망이 꺼지기보다 공허로 바뀔 수 있습니다.
    -   v3: 몰입이 깊어질수록 소진을 막는 조율이 필요해집니다.
-   intimacyStyle
    -   v1: 친밀은 순간 자극보다 약속과 의미가 생길 때 더 깊어질 수 있습니다.
    -   v2: 관계가 ‘내 것’이 되는 순간 욕망이 강하게 붙을 수 있습니다.
    -   v3: 끝까지 가려는 힘이 부담으로 바뀌지 않도록 경계가 필요합니다.

## SEEKER

-   summaryStyle
    -   v1: 익숙해지는 순간, 욕망의 온도가 빠르게 떨어질 수 있습니다.
    -   v2: 예측 불가능한 긴장이 끌림을 키우는 편입니다.
    -   v3: 새로운 장면이 열릴수록 욕망은 더 선명해집니다.
-   structureStyle
