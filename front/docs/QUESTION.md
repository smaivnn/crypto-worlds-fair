1. 직접 묻지 않는다
2. 얕아 보이게 묻는다
3. 상황/비유 중심
4. 옳고 그름 없음
5. 욕망 축을 은근히 건드린다

# 질문 목록 (8문항)

Q1. 낯선 상황에 던져졌을 때 당신의 반응은?

-   구조를 잡는다
-   흐름을 본다
-   그냥 몸을 던진다
-   벗어난다

Q2. 관계에서 가장 불편한 순간은?

-   내가 통제하지 못할 때
-   예측이 깨질 때
-   관심이 사라질 때
-   묶여 있다고 느낄 때

Q3. 선택을 미룰 수 없는 순간, 당신은?

-   내가 결정한다
-   기준을 찾는다
-   누군가의 반응을 본다
-   새로운 길을 고른다

Q4. 반복되는 하루가 주어졌다면?

-   구조를 다듬는다
-   의미를 해석한다
-   벗어나고 싶어진다
-   안정되면 괜찮다

Q5. 이성 관계에서 끌리는 순간은?

-   역할이 분명할 때
-   감정이 깊이 연결될 때
-   긴장이 흐를 때
-   자유롭게 오갈 수 있을 때

Q6. 목표를 세울 때 중요한 건?

-   내가 주도하는가
-   오래 갈 수 있는가
-   몰입할 수 있는가
-   더 위로 가는가

Q7. 갈등이 생기면?

-   정리하려 한다
-   책임지려 한다
-   피하거나 관찰한다
-   깨버리고 싶어진다

Q8. 당신을 가장 지치게 하는 상태는?

-   결정권이 없을 때
-   의미가 없을 때
-   자극이 없을 때
-   묶여 있을 때
