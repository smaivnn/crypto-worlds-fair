# 점수 계산 구조

## 비율

-   질문: 40%
-   사주: 40%
-   점성: 20%

---

## 질문 점수

-   각 질문 선택지는 12유형 중 일부에 가중치 부여
-   모든 질문 합산 후 normalize

---

## 사주 보정 (간이)

-   연/월/일
-   오행 비중 산출
-   오행 → 욕망 유형 매핑

### 출생 연

해당 오행에 + 1

ex) 98년생 -> 토 + 1

| 출생연 끝자리 | 오행   |
| ------------- | ------ |
| 0, 1          | 금(金) |
| 2, 3          | 수(水) |
| 4, 5          | 목(木) |
| 6, 7          | 화(火) |
| 8, 9          | 토(土) |

---

### 출생 월

해당 오행에 + 3

ex) 03월생 -> 목 + 3

| 월   | 오행   |
| ---- | ------ |
| 3–5  | 목(木) |
| 6–8  | 화(火) |
| 9–11 | 금(金) |
| 12–2 | 수(水) |

### 출생 일

해당 오행에 + 2

ex) 21일생 -> 금 + 2

| 출생 ‘일’ | 오행   |
| --------- | ------ |
| 1~6       | 목(木) |
| 7~12      | 화(火) |
| 13~18     | 토(土) |
| 19~24     | 금(金) |
| 25~31     | 수(水) |

### 보정치

| 오행   | +1.5      | +0.5      |
| ------ | --------- | --------- |
| 목(木) | ASCENDER  | SEEKER    |
| 화(火) | WITNESS   | REBELLION |
| 토(土) | ANCHOR    | GUARDIAN  |
| 금(金) | SOVEREIGN | CURATOR   |
| 수(水) | SPECTATOR | NOMAD     |

ex) 토1 / 목3 / 금2 -> Anchor 1.5, GUARDIAN 05 / ASCENDER 4.5, SEEKER 1.5 / SOVEREIGN 3.0, CURATOR 1 / 나머지 0

## 점성 보정 (간이)

-   태양/달 원소
-   원소 → 욕망 유형 매핑

### 점수 계산 변환

1. 12별자리 -> 4원소 변환

| 원소 | 별자리             |
| ---- | ------------------ |
| 불   | 양, 사자, 사수     |
| 흙   | 황소, 처녀, 염소   |
| 공기 | 쌍둥이, 천칭, 물병 |
| 물   | 게, 전갈, 물고기   |

2. 4원소 -> 욕망으로 변환

| 원소 | 욕망 방향      |
| ---- | -------------- |
| 불   | 자극·표현·돌파 |
| 흙   | 안정·유지·책임 |
| 공기 | 해석·관계·의미 |
| 물   | 친밀·흐름·감정 |

3. 욕망 점수 매핑

| 원소 | +1.5    | +0.5      |
| ---- | ------- | --------- |
| 불   | SEEKER  | REBELLION |
| 흙   | ANCHOR  | GUARDIAN  |
| 공기 | CURATOR | WITNESS   |
| 물   | MERGER  | SPECTATOR |

## 최종 산출

-   finalScore = 0.4 _ 질문 + 0.4 _ 사주 + 0.2 \* 점성
-   최고 점수: 주 욕망
-   차순위: 보조 욕망

---

### 추천 계산식

```ts
BaseScore[type] = 0.4 * SajuScore[type] + 0.2 * AstrologyScore[type];

FinalScore[type] = BaseScore[type] + 0.4 * QuestionScore[type];
```

## Confidence

-   주/보조 점수 차이 기반
-   결과 신뢰도 표시용
