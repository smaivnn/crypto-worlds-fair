# Routes

## 필수 라우팅

/  
- 랜딩 페이지
- 서비스 소개 + 시작 CTA

/profile  
- 생년월일 입력
- 출생시간/출생지 선택 입력

/questions  
- 욕망 분류 질문 (총 8문항)

/result  
- 무료 결과 리포트
- 욕망 유형 요약 + 프리뷰

/pay  
- 유료 안내 및 결제

/report  
- 유료 리포트
- 결제 완료 사용자만 접근 가능

/legal  
- 이용약관 / 개인정보 / 면책

---

## 선택 라우팅 (확장)

/r/:token  
- 공유 링크로 결과 접근

/settings  
- 로컬 저장 정보 확인/초기화
